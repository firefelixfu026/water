# ToTwist 一拧

「一拧即释，让营养融入日常饮水」个性化营养瓶盖概念设计网页。

## 本地预览

直接使用浏览器打开 index.html。网页为静态前端，不需要安装依赖或启动构建流程。

## 页面内容与交互

- 产品首页、瓶盖释放示意、四步使用流程。
- ToTwist 产品主视觉、瓶盖细节与使用场景图、首购套装介绍和补购入口。图库支持点击缩略图切换主图。
- 页面采用用户提供的 ToTwist 产品概念图片；瓶身外观参考磨砂圆柱瓶与旋拧环设计，瓶盖内部释放结构参考独立粉仓结构示意。两者为概念设计，尚非量产产品。
- ToTwist 标识依据用户提供的 logo 方向绘制为 SVG，英文品牌名与中文产品说明由 HTML 文字呈现。
- 产品展示区按电商商品详情页组织：产品大图、套装配置、示意价格和购买前说明集中呈现。
- 标准配方方向展示及成分透明说明。
- 营养匹配表单：收集年龄、饮食习惯、过敏、现有补剂和相关健康情况。
- 对未成年人、孕哺期、特殊医学营养管理、疾病或用药情况停止自动推荐，并显示专业评估提示。
- 成人匹配结果仅显示“待专业审核”，不生成剂量处方或直接购买配方。
- 可选健康资料上传控件仅显示本地文件名，不读取或上传文件内容。
- 匹配表单精简重复小字；本地信息处理与演示范围可点击“信息说明”查看。
- 首购套装和补充装概念价格、配方追溯信息、购买前说明与常见问题。
- 响应式布局，适配桌面与移动屏幕。

所有配方和价格均为概念示意。网页不处理订单、支付或真实 AI 分析。正式上线前仍需完成产品类别判断、配方研发与验证、专业审核、质量体系、隐私授权及生产适配验证。

## 文件

- index.html：页面结构与内容
- styles.css：页面样式与响应式布局
- app.js：匹配流程、适用性拦截、信息弹窗与菜单交互
- styles-storefront.css、styles-retail.css：品牌视觉、电商商品详情排版与响应式布局
- assets/totwist-mark.svg：ToTwist 图形标识
- assets/totwist-*.png：用户提供的产品组合、瓶盖细节与生活方式概念图
- assets/onetwist-*.png：早期 AI 生成概念图，仅保留在项目中作设计记录，当前页面不再展示
- AI_USAGE.md：AI 使用简要记录
